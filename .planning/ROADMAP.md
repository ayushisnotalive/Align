### Phase 6: Explore (Live space) (`live`, `map`)
Implement an interactive map view showing other active users in real time. Features include location clustering, fetching active users within bounds, and map-based interactions.

### Phase 7: Safety & Admin (`block`, `admin`, `blue_tick`)
Implement reporting, blocking functionality, administrative moderation tools, and the verified (blue tick) status.

### Phase 8: Hardening (`tests`, `purge`)
Comprehensive testing, security hardening, data retention jobs, and purging of stale location data.

### Phase 9: Release (`play_console`, `prod_db`)
Final production deployment tasks including App Store/Play Console submissions and migrating the production database schema.
