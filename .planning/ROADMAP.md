### Phase 6: Explore (Live space) (`live`, `map`)
Implement an interactive map view showing other active users in real time. Features include location clustering, fetching active users within bounds, and map-based interactions.

### Phase 7: Comprehensive Profile (`profile_expansion`, `onboarding`)
Massive expansion of the user profile covering demographics, lifestyle, interests, prompts, and rich media (videos, voice prompts) as well as third-party integrations (Spotify, Instagram). Update schema and onboarding flows.

### Phase 8: Premium & Gamification (`premium`, `rich_media`, `gamification`)
Add monetization tier features (Super Likes, Boost, Rewind, Read Receipts), Rich Chat & Media (Voice notes, Video/Audio calling, media sharing), and Engagement (Standouts, Speed Dating, Push Notifications).

### Phase 9: Premium Expansion (`who_likes_you`, `advanced_filters`)
Implement the dedicated "Who Likes You" screen grid for premium users, and Advanced Filters (height, education, lifestyle) that apply to the discover feed.

### Phase 10: Safety & Admin (`block`, `admin`, `blue_tick`)
Implement reporting, blocking functionality, administrative moderation tools, and the verified (blue tick) status.

### Phase 11: Hardening (`tests`, `purge`)
Comprehensive testing, security hardening, data retention jobs, and purging of stale location data.

### Phase 12: Release (`play_console`, `prod_db`)
Final production deployment tasks including App Store/Play Console submissions and migrating the production database schema.
